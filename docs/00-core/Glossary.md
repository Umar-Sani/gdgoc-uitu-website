# Glossary

Domain and project-specific terms. General web vocabulary is not repeated here.

## A

**ADR** — Architecture Decision Record. One decision per file in
[[../04-decisions/_Decisions_Index|04-decisions]], written *before* implementing.

**AFD** — Application Flow Document. One of the frozen course specifications; describes
screen-by-screen user journeys. See [[../07-build-docs/_Build_Docs_Index|07-build-docs]].

**`app.current_user_id`** — a PostgreSQL session setting that RLS policies and the audit
trigger read to identify the acting user. **The backend never sets it**, which is why RLS is
inert and audit rows have a NULL actor. See `BUG-003`, `BUG-004`.

**Audit partition** — a monthly range partition of `audit.logs`. Twelve exist, covering 2026
only.

## B

**Build phase** — a delivery milestone from the original build, named in commit messages
("Phase 5 Completed: Added Forum Screens"). Ran Mar–Jun 2026 and is finished. **Not** the same
as a doc phase — always qualify the word.

**BUG-NNN** — a defect in shipped code, tracked in [[../01-planning/bugs|bugs]].

## C

**Chapter** — the GDGoC student organisation at UIT University, Karachi. The platform's
subject.

**CMS** — the admin-editable site content: homepage, about sections, team members, teams,
sponsors, featured events, testimonials, gallery. Served under `/api/cms/*`.

## D

**Doc phase** — a stage in the documentation roadmap at [[../01-planning/Phases|Phases]].
Numbered independently of build phases.

**DSD** — Database Schema Document, one of the frozen course specifications.

**Dual write** — the end-of-session rule: append to `handoff.md` **and** update the vault in
place. Doing only the first is the most common documentation failure here.

## E

**Editor** — the lowest privileged staff role. May manage events and event people, and reach
the admin dashboard, but is blocked from `/admin/cms/*`, user management, payments and the
audit log.

**`EVENT_FULL`** — the exception raised when registering against a full event. Raised in two
places with slightly different text: `register_user_for_event` and the `trg_seat_counter`
trigger.

## G

**GDGoC** — Google Developer Groups on Campus. **UITU** — UIT University. Together, the
chapter this platform serves.

**`gdgoc_app`** — the database role created by the schema file, with the literal placeholder
password `CHANGE_IN_PRODUCTION`. See `TODO-015`.

## I

**Invoice number** — `INV-<YYYY>-<6-digit sequence>`, e.g. `INV-2026-000042`, generated by
`process_payment` from `payments.invoice_seq` on successful payment only.

## M

**Mock auth** — a development bypass. Backend: the literal token `mock-token` authenticates as
a hard-coded admin UUID when `NODE_ENV !== 'production'` **and** `ALLOW_MOCK_AUTH === 'true'`.
Frontend: `lib/mockAuth.ts`, gated by a hard-coded `MOCK_ENABLED` constant, currently `false`.

## P

**PSP** — the seven-file feature documentation set (OST, FST, SST, LST, API, Security, Tests).
See [[../05-features/_PSP_Template|the template]].

**PRD / SRD** — Product / Software Requirements Document. Frozen course specifications.

## R

**RLS** — Row Level Security. Enabled on five tables here, with policies that never take effect
because the session settings they depend on are never set, and the connecting role is an owner
that bypasses RLS anyway.

## S

**Seat counter** — `trg_seat_counter`, the `AFTER INSERT OR DELETE` trigger on
`events.registrations` that maintains `events.seats_registered` and re-checks capacity.

**SERIALIZABLE** — the PostgreSQL isolation level wrapped around event registration and payment
settlement, the two paths where a race could overbook an event.

**Soft delete** — marking a row rather than removing it: threads and replies set
`is_deleted = TRUE`; cancelled events set `status = 'cancelled'`.

**Super admin** — the highest role. Exclusively may grant super_admin, delete users, and read
the audit log. Roles are a **flat allow-list**, so `super_admin` is not implicitly admitted by
`requireRole('admin')`.

## T

**Transactional notification** — a notification type that always emails regardless of user
preference. Exactly one qualifies: `registration_confirmed`.

**`tsv`** — the `TSVECTOR` column on `forum.threads`, maintained by a `BEFORE` trigger and
indexed with GIN. Powers forum search.

**TODO-NNN** — a traceability row in [[../01-planning/TODO|TODO]]. Unrelated to GitHub issues
or PR numbers; this project uses no issue tracker.

## V

**Vault** — this `docs/` directory. Answers "what is true now", and is rewritten in place.

**Vendored types** — `shared/types.ts` copied into `frontend/shared/types.ts` so Vercel's
frontend-rooted build can reach it. Two files, nothing syncing them. See `TODO-001`.

**Viewer** — a role seeded in `users.roles` but never assignable through the API, and filtered
out of `GET /api/admin/roles`. Effectively vestigial.
